# Data attribution

Locus does not contain or redistribute the GeoHistory dataset. It requests event records from the public GeoHistory API and renders them in the browser.

GeoHistory derives event data from Wikidata (CC0) and Wikipedia-linked sources. Wikipedia-derived text is distributed under the Creative Commons Attribution-ShareAlike license (CC BY-SA 4.0).

Every displayed historical event must include the event's `source_url` as its per-item attribution link. Client code must not discard, replace, or hide that attribution.

- GeoHistory: https://github.com/noffsingercb/GeoHistory
- Wikidata: https://www.wikidata.org/
- CC BY-SA 4.0: https://creativecommons.org/licenses/by-sa/4.0/
